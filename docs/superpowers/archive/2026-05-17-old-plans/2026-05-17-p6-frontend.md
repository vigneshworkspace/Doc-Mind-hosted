> **Prerequisite:** P1–P5 complete. Backend running at localhost:8000. Vite dev server running (proxies `/api/v1` to `localhost:8000`).

**Goal:** Replace every mock dispatch and fake timeout in all 19 DocMind screens with real API calls to the FastAPI backend, while keeping mock data as a graceful offline fallback.

**Architecture:** The existing `api/client.js` request helper is updated to read a JWT from `localStorage` and inject it as a Bearer token; a new `api/stream.js` helper handles SSE streaming for chat endpoints. Each screen gets a `useEffect` mount fetch that calls the relevant `api/index.js` method and dispatches `set-*` actions to replace the full list in state, falling back silently to whatever mock data is already in `initialState` if the call fails. Auth.jsx becomes the real entry point — it POSTs credentials, stores the returned token, and calls `onAuth` only on HTTP 200.

**Tech Stack:**
- React 18 + Vite (existing)
- `fetch` + `ReadableStream` for SSE (no EventSource, avoids POST limitation)
- `localStorage` for JWT persistence
- React Testing Library + `jest` for Auth unit tests; manual smoke tests for all screens
- Existing `useReducer` + `data/index.js` for state (new `set-*` actions added)

```js
// frontend/src/api/client.js
// Base API client — all calls proxy through Vite to FastAPI at /api/v1

const BASE = '/api/v1';

// ── Token helpers ─────────────────────────────────────────────
export const getToken = () => localStorage.getItem('docmind_token');
export const setToken = (t) => localStorage.setItem('docmind_token', t);
export const clearToken = () => localStorage.removeItem('docmind_token');

// ── Core request ──────────────────────────────────────────────
async function request(method, path, body) {
  const token = getToken();
  const headers = { 'Content-Type': 'application/json' };
  if (token) headers['Authorization'] = `Bearer ${token}`;

  const res = await fetch(`${BASE}${path}`, {
    method,
    headers,
    body: body ? JSON.stringify(body) : undefined,
    credentials: 'include',
  });

  if (!res.ok) {
    const err = await res.json().catch(() => ({ detail: res.statusText }));
    throw new Error(err.detail || `HTTP ${res.status}`);
  }
  return res.json();
}

export const api = {
  get:    (path)        => request('GET',    path),
  post:   (path, body)  => request('POST',   path, body),
  put:    (path, body)  => request('PUT',    path, body),
  patch:  (path, body)  => request('PATCH',  path, body),
  delete: (path)        => request('DELETE', path),
};
```

## Task 2: SSE Streaming Helper

**Files:** `frontend/src/api/stream.js` (new file)

- [ ] **Step 1: Create `stream.js`**

```js
// frontend/src/api/stream.js
// Async generator for Server-Sent Events over POST (fetch + ReadableStream).
// Yields each raw data payload string. Stops at [DONE].

import { getToken } from './client.js';

export async function* streamSSE(path, body) {
  const token = getToken();
  const headers = { 'Content-Type': 'application/json' };
  if (token) headers['Authorization'] = `Bearer ${token}`;

  const resp = await fetch(`/api/v1${path}`, {
    method: 'POST',
    headers,
    body: JSON.stringify(body),
    credentials: 'include',
  });

  if (!resp.ok) {
    const err = await resp.json().catch(() => ({ detail: resp.statusText }));
    throw new Error(err.detail || `HTTP ${resp.status}`);
  }

  const reader = resp.body.getReader();
  const dec = new TextDecoder();
  let buf = '';

  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    buf += dec.decode(value, { stream: true });
    const lines = buf.split('\n');
    buf = lines.pop(); // keep incomplete last line
    for (const line of lines) {
      if (line.startsWith('data: ')) {
        const data = line.slice(6).trim();
        if (data === '[DONE]') return;
        if (data) yield data;
      }
    }
  }
}
```

## Task 19: VoiceChat Screen (FastRTC WebSocket)

**Files:** `frontend/src/screens/VoiceChat.jsx`

- [ ] **Step 1: Replace fake setTimeout simulation with real FastRTC WebSocket**

```jsx
// frontend/src/screens/VoiceChat.jsx — full component rewrite
import { useState, useRef, useEffect } from 'react';
import { Icon } from '../components/Shell.jsx';
import { getToken } from '../api/client.js';

export default function VoiceChat() {
  const [status, setStatus] = useState('idle'); // idle | listening | thinking | speaking
  const [transcript, setTranscript] = useState('');
  const [reply, setReply] = useState('');
  const [error, setError] = useState('');
  const wsRef = useRef(null);
  const mediaRef = useRef(null);

  // Cleanup on unmount
  useEffect(() => {
    return () => {
      wsRef.current?.close();
      mediaRef.current?.getTracks().forEach(t => t.stop());
    };
  }, []);

  async function start() {
    if (status !== 'idle') {
      // Stop active session
      wsRef.current?.close();
      mediaRef.current?.getTracks().forEach(t => t.stop());
      setStatus('idle');
      return;
    }

    setError('');
    setTranscript('');
    setReply('');

    try {
      // Request microphone access
      const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
      mediaRef.current = stream;
      setStatus('listening');

      const token = getToken();
      const wsUrl = `ws://localhost:8000/api/v1/voice/ws${token ? `?token=${token}` : ''}`;
      const ws = new WebSocket(wsUrl);
      wsRef.current = ws;

      // Stream mic audio as binary frames
      const audioCtx = new AudioContext({ sampleRate: 16000 });
      const source = audioCtx.createMediaStreamSource(stream);
      const processor = audioCtx.createScriptProcessor(4096, 1, 1);
      processor.onaudioprocess = (e) => {
        if (ws.readyState !== WebSocket.OPEN) return;
        const pcm = e.inputBuffer.getChannelData(0);
        const buf = new Int16Array(pcm.length);
        for (let i = 0; i < pcm.length; i++) {
          buf[i] = Math.max(-32768, Math.min(32767, pcm[i] * 32768));
        }
        ws.send(buf.buffer);
      };
      source.connect(processor);
      processor.connect(audioCtx.destination);

      ws.onmessage = (event) => {
        try {
          const msg = JSON.parse(event.data);
          if (msg.type === 'transcript') {
            setTranscript(msg.text);
            setStatus('thinking');
          } else if (msg.type === 'reply') {
            setReply(msg.text);
            setStatus('speaking');
          } else if (msg.type === 'done') {
            setStatus('idle');
          }
        } catch {
          // Binary audio response — ignore (TTS handled by backend)
        }
      };

      ws.onerror = () => {
        setError('WebSocket connection failed. Is the backend running?');
        setStatus('idle');
      };

      ws.onclose = () => {
        source.disconnect();
        processor.disconnect();
        audioCtx.close();
        stream.getTracks().forEach(t => t.stop());
        if (status !== 'idle') setStatus('idle');
      };

    } catch (err) {
      setError(err.message || 'Microphone access denied.');
      setStatus('idle');
    }
  }

  const colors = status === 'listening' ? 'var(--accent)' : status === 'speaking' ? 'var(--ok)' : 'var(--ink-3)';
  const label = status === 'idle' ? 'Tap to talk' : status === 'listening' ? 'Listening' : status === 'thinking' ? 'Thinking' : 'Speaking';

  return (
    <div className="col" style={{ gap: 32, height: '100%', justifyContent: 'center', alignItems: 'center', padding: '40px 20px' }}>
      <div className="t-eyebrow">{label}</div>

      {error && (
        <div style={{ color: 'var(--err, #dc2626)', fontSize: 13, textAlign: 'center', maxWidth: 320 }}>{error}</div>
      )}

      <div
        onClick={start}
```

## Notes for Agentic Workers

1. **Token expiry**: The backend may return HTTP 401 if the JWT expires. Add a global intercept in `client.js` `request()`: if `res.status === 401`, call `clearToken()` and `window.location.reload()` to force re-login. This is a one-liner guard before `throw`.

2. **CORS**: Vite's dev proxy handles CORS. In production, the FastAPI backend must set `Access-Control-Allow-Origin` and `Access-Control-Allow-Credentials`.

3. **Backend shape mismatches**: The `api/index.js` methods assume the backend returns objects matching the frontend state shape (e.g. `{ id, name, size, type, uploadDate, tags }`). If the backend uses snake_case (`upload_date`), add a thin mapper in `api/index.js` per endpoint.

4. **SSE and AbortController**: For AI Chat, if the user sends a new message before the previous stream completes, cancel the in-flight stream. Add an `AbortController` ref and call `abort()` on new send. Pass the signal to `fetch()` in `streamSSE`. This is a polish task, not a blocker.

5. **VoiceChat AudioContext**: Some browsers block `AudioContext` until a user gesture. The `start()` function is triggered by a click, which satisfies this requirement.
